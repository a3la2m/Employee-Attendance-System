# نظام إدارة الحضور والرواتب 🕐💰

تطبيق سطح مكتب لويندوز لإدارة حضور وانصراف الموظفين عبر **بصمة الأصابع**، وحساب
الرواتب تلقائياً، وإنتاج تقارير احترافية عربية (RTL) قابلة للطباعة أو الحفظ PDF.

مبني على **Tauri 2** (خلفية Rust) + **React/TypeScript** + **Tailwind CSS** + **SQLite**،
ومتصل بجهاز بصمة **ZKTeco K50 Pro** عبر الشبكة المحلية (LAN).

---

## ✨ المزايا

- **جهاز البصمة**: سحب تلقائي للسجلات عند الإقلاع ثم دوريّاً، ومطابقتها مع قاعدة البيانات
  المحلية (بدون تكرار). يعمل عبر **بروتوكول ZK (منفذ 4370) بـ Rust نقي**، مع **طبقة DLL
  (FFI لـ `plcommpro.dll`)** جاهزة على ويندوز.
- **الموظفون**: إضافة/تعديل/حذف + ربط رقم البصمة (PIN) بالموظف.
- **الحضور**: احتساب تلقائي (حضور/غياب/تأخير/انصراف مبكر/عمل إضافي) لكل يوم.
- **الرواتب**: كل المعادلات قابلة للتعديل من الإعدادات (انظر أدناه).
- **التقارير**: كشف رواتب شهري + تقرير حضور يومي، بتصميم طباعة عربي RTL بشعار الشركة
  وتذييل (توقيع / ختم / تاريخ) — طباعة مباشرة أو حفظ PDF.
- **صينية نظام (Tray) + إقلاع تلقائي** مع ويندوز، والتطبيق يعمل في الخلفية.
- **فحص ساعة الجهاز** مقابل المنطقة الزمنية `Asia/Jerusalem` (قابلة للتغيير) + ضبط مباشر.
- **رصد مستخدم ويندوز جديد** → إشعار + طلب البيانات الأساسية لربطه بالبصمة.
- **تنبيه/مزامنة فورية** عبر إشعارات النظام.

## 🧮 معادلات الرواتب (افتراضية — كلها قابلة للتعديل)

| البند | القاعدة | الافتراضي |
|---|---|---|
| العمل الفعلي | `(الانصراف − الحضور) − الاستراحة` | استراحة 30 د |
| الأجر الأساسي | `الساعات الفعلية × سعر الساعة` | 8.5 سا · 10 ₪/سا |
| البدلات | `(فطور + مواصلات) × أيام الحضور` | 7 + 5 ₪/يوم |
| الخصومات | `(ساعات التأخير + ساعات الغياب) × سعر الساعة` | — |
| العمل الإضافي | `ما زاد عن ساعات الدوام × سعر الساعة × المضاعف` | بعد 8.5 سا · ×1.5 |
| **الصافي** | `الأساسي + البدلات − الخصومات` | — |

عطلة نهاية الأسبوع الافتراضية: **الجمعة والسبت** (`weekend_days = 4,5`).

## 🔌 إعداد جهاز البصمة

1. اضبط ثابت الـIP للجهاز (مثال `192.168.1.205`)، المنفذ `4370`.
2. من صفحة **«جهاز البصمة»** في التطبيق أدخل الـIP والمنفذ و**CommKey** ثم «فحص الاتصال».
3. للـDLL (اختياري على ويندوز): ضع `plcommpro.dll` في مجلد `zk` بجانب الملف التنفيذي —
   إن لم يوجد يسقط التطبيق تلقائياً للبروتوكول النقي (يعمل بلا DLL).

> الأمان: غيّر `CommKey` من الإعدادات الافتراضية، وأغلق منفذ 23 (telnet)، واعزل الجهاز
> في VLAN، لأن منفذ 4370 محميّ بمفتاح مشترك افتراضي `0` فقط.
