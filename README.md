# نظام إدارة الحضور والرواتب 🕐💰

تطبيق سطح مكتب لويندوز لإدارة حضور وانصراف الموظفين عبر **بصمة الأصابع**، وحساب
الرواتب تلقائياً، وإنتاج تقارير احترافية عربية (RTL) قابلة للطباعة أو الحفظ PDF.

مبني على **Tauri 2** (خلفية Rust) + **React/TypeScript** + **Tailwind CSS** + **SQLite**،
ومتصل بجهاز بصمة **ZKTeco K50 Pro** عبر الشبكة المحلية (LAN).

> 📌 **الجديد في 0.2.0**: تصحيح احتساب الحضور («بصمة ناقصة» / «قيد العمل»)، إجازات
> وعطل رسمية، أزرار يومية (استراحة/بدل فطور)، وتسريع لوحة التحكم — التفاصيل في
> [CHANGELOG.md](CHANGELOG.md).

## ✨ المزايا

- **جهاز البصمة**: سحب تلقائي للسجلات عند الإقلاع ثم دوريّاً، ومطابقتها مع قاعدة البيانات
  المحلية (بدون تكرار). يعمل عبر **بروتوكول ZK (منفذ 4370) بـ Rust نقي**، مع **طبقة DLL
  (FFI لـ `plcommpro.dll`)** جاهزة على ويندوز.
- **الموظفون**: إضافة/تعديل/حذف + ربط رقم البصمة (PIN) بالموظف.
- **تخصيص لكل موظف**: تفعيل/تعطيل **العمل الإضافي بالمضاعف** لموظف بعينه،
  واستثناء أي موظف من **بدل الفطور و/أو بدل المواصلات** (البدلات افتراضية للجميع).
- **الحضور**: احتساب تلقائي لكل يوم (حضور / إجازة / عطلة رسمية / عطلة أسبوعية / غياب /
  **بصمة ناقصة** / انصراف مبكر / عمل إضافي)، مع **تعديل يدوي لأي يوم** (نسيان بصمة أو
  عطل في الجهاز)، و**تحويل اليوم إلى إجازة** (سنوية بخصم من الرصيد / مرضية / بلا أجر)،
  وزرّي اليوم: **إلغاء خصم الاستراحة** و**إزالة بدل الفطور** لذلك اليوم.
- **أنواع الحضور** (كم تُقرأ الحالة): الدوام المتأخر **حضوره حضور** (التأخير رقم في عموده
  فقط)، والوردية الجارية (دخول بلا انصراف بعد) **حضور + «قيد العمل»**، ويُعلَّم اليوم
  **«بصمة ناقصة»** إذا سُجّل خروج بلا دخول، أو بقي دخول بلا انصراف **14 ساعة**
  (`OPEN_PUNCH_GRACE_MIN`) ليتدخّل المسؤول يدوياً.
- **الإجازات والعطل**: رصيد إجازات سنوية مع استحقاق شهري تلقائي، وإدارة الإجازات
  (سنوية/مرضية/بلا أجر، مدفوعة أو لا)، وإدارة **العطل الرسمية**.
- **الرواتب**: كل المعادلات قابلة للتعديل من الإعدادات (انظر أدناه)، مع **أرشيف شهري**
  («إغلاق الشهر») وسجل رواتب لكل موظف.
- **التقارير**: كشف رواتب شهري + تقرير حضور يومي، بتصميم طباعة عربي RTL بشعار الشركة
  وتذييل (توقيع / ختم / تاريخ) — طباعة مباشرة أو حفظ PDF.
- **التخزين والنسخ الاحتياطي**: مكان قاعدة SQLite قابل للاختيار (مثلاً مجلد
  **Google Drive** المتزامن) — كل الملفات بأسماء إنجليزية منظّمة في مجلد واحد،
  مع زر «نسخ احتياطي الآن» (لقطة `VACUUM INTO` + `attendance-settings.json`).
- **صينية نظام (Tray) + إقلاع تلقائي** مع ويندوز، والتطبيق يعمل في الخلفية.
- **فحص ساعة الجهاز** مقابل المنطقة الزمنية `Asia/Jerusalem` (قابلة للتغيير) + ضبط مباشر.
- **رصد مستخدم ويندوز جديد** → إشعار + طلب البيانات الأساسية لربطه بالبصمة.
- **تنبيه/مزامنة فورية** عبر إشعارات النظام.

## 🧮 معادلات الرواتب (افتراضية — كلها قابلة للتعديل)

| البند | القاعدة | الافتراضي |
|---|---|---|
| العمل الفعلي | `(الانصراف − الحضور) − الاستراحة` | استراحة 30 د |
| الأجر الأساسي | `الساعات الفعلية × سعر الساعة` | 8.5 سا · 10 ₪/سا |
| البدلات | `(فطور + مواصلات) × أيام الحضور` | 7 + 5 ₪/يوم |
| الخصومات | **لا خصومات**: التأخير والغياب لا يُخصم منهما شيء — الغياب يعني عدم استحقاق ساعاته فقط | 0 |
| العمل الإضافي | `ما زاد عن ساعات الدوام × سعر الساعة × المضاعف` | بعد 8.5 سا · ×1.5 |
| بدل العطلة الأسبوعية | أسبوعياً: `62 ÷ 6 أيام دوام`، وكل يوم غياب يُخصم نصيبه؛ والدوام في يوم العطلة يُدفع ساعاته بالمضاعف ولا يمنع البدل | 62/أسبوع |
| الإجازة | المدفوعة تُحتسب يوماً مستحقاً (بلا ساعات)، وغير المدفوعة تُهمَل بلا خصم | — |
| **الصافي** | `الأساسي + البدلات + بدل العطلة − الخصومات` | — |

عطلة نهاية الأسبوع الافتراضية: **الجمعة** (`weekend_days = 4`) — قابلة للتعديل،
ويمكن إلغاء دفع بدل العطلة لموظف بعينه.

الإضافي لكل موظف: مضاعف عام من الإعدادات (`overtime_rate_mult`, افتراضي 1.5) — يُعطَّل
لموظف بعينه فيُحسب ساعته الإضافية **بالسعر العادي (×1.0)** دون فقدان حقه بالساعة نفسها.

## 💾 مكان قاعدة البيانات والنسخ الاحتياطي

الملفات كلها في مجلد واحد بأسماء إنجليزية، ويمكن اختيار المجلد من الإعدادات
(اختر مجلد Google Drive / Dropbox المتزامن فيتم النسخ تلقائياً):

```text
<المجلد المختار>/
├── attendance.db                          # قاعدة البيانات (SQLite)
├── attendance-settings.json               # نسخة JSON من كل الإعدادات
└── attendance-backup-YYYYMMDD-HHMMSS.db   # لقطات القاعدة (VACUUM INTO)
```

- المؤشّر للمجلد المختار يُحفظ في `storage-config.json` داخل مجلد إعدادات التطبيق.
- **🛟 نسخ احتياطي الآن** (الإعدادات): لقطة ثابتة وآمنة للقاعدة + تصدير الإعدادات.
- **♻️ استعادة الإعدادات**: يُعيد إعدادات `attendance-settings.json` للقاعدة.

## 🚀 التطوير

```bash
npm install
npm run tauri dev
```

### الاختبارات (منطق الرواتب والحضور)

```bash
cd src-tauri && cargo test            # اختبارات الخلفية (68 اختباراً)
npm test                              # اختبارات الواجهة (Vitest)
```

اختبار حيّ ضد الجهاز الحقيقي (اختياري، لا يعمل في CI):

```bash
cd src-tauri
ZK_IP=192.168.1.205 cargo test live_device -- --ignored --nocapture
```

### البناء الإنتاجي (ويندوز)

```bash
npm run tauri build      # → .msi و .exe
```

أو عبر **GitHub Actions** (`.github/workflows/build-windows.yml`) — يبني تلقائياً على
`windows-latest` ويرفع المثبّتات كـ Artifacts.

### التشغيل على لينكس (مثل Linux Mint — بدون صلاحيات مدير)

```bash
./build-linux.sh   # يبني الواجهة ثم الملف التنفيذي بالطريقة الصحيحة
./run-linux.sh     # تشغيل التطبيق مباشرة
```

> لا تستخدم `cargo build --release` وحده: يبني Tauri بوضع التطوير (devUrl) فتظهر
> رسالة «تعذّر الاتصال بـ localhost». استخدم `build-linux.sh` أو أضف
> `--features custom-protocol`.

## 🔌 إعداد جهاز البصمة

1. اضبط ثابت الـIP للجهاز (مثال `192.168.1.205`)، المنفذ `4370`.
2. من صفحة **«جهاز البصمة»** في التطبيق أدخل الـIP والمنفذ و**CommKey** ثم «فحص الاتصال».
3. للـDLL (اختياري على ويندوز): ضع `plcommpro.dll` في مجلد `zk` بجانب الملف التنفيذي —
   إن لم يوجد يسقط التطبيق تلقائياً للبروتوكول النقي (يعمل بلا DLL).

> الأمان: غيّر `CommKey` من الإعدادات الافتراضية، وأغلق منفذ 23 (telnet)، واعزل الجهاز
> في VLAN، لأن منفذ 4370 محميّ بمفتاح مشترك افتراضي `0` فقط.

## 🗄️ قاعدة البيانات (SQLite)

الجداول: `settings` · `employees` · `punches` (خام، فريد بـ pin+time لمنع التكرار) ·
`attendance_days` (محسوب) · `leaves` · `holidays` · `notifications` · `payroll_runs` (أرشيف).
تُنشأ تلقائياً في مجلد بيانات التطبيق (`app_data_dir/attendance.db`)، والترحيلات
(`migrate_column`) تضيف الأعمدة الجديدة لقواعد موجودة بلا فقدان بيانات.
